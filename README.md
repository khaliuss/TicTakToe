## 📌 О проекте

Это простой пет-проект, созданный для практики **процедурного программирования** и первого погружения в основы **backend-разработки**.

В процессе разработки отрабатывались базовые концепции:
* Работа с двумерными массивами и циклами;
* Декомпозиция кода на отдельные функции и методы;
* Управление состоянием игры и проверка условий победы;
* Оформление консольного интерфейса с помощью ANSI-цветов и Unicode-псевдографики.
